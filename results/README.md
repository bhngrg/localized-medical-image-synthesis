# Results

This directory contains curated scientific results from the finalized analyses
in this repository. Raw evaluation products, intermediate artifacts, and
run-specific outputs are maintained separately under `outputs/`.

## Downstream synthetic-augmentation evaluation

The downstream experiment evaluates whether synthetic images generated after
parameter-efficient adaptation can improve a separate tumor-segmentation task.

The image-generation models are not evaluated using their own training
objective. Instead, synthetic images generated by each adaptation method are
added to a fixed real BraTS downstream-training set, a separate segmentation
model is trained, and that model is evaluated on an independent external
cohort.

The finalized comparison contains seven downstream training regimes:

1. **Real only**
2. **Real + BR-LoRA posterior mean**
3. **Real + BR-LoRA posterior sampling**
4. **Real + Regional LoRA**
5. **Real + DoRA**
6. **Real + LoKr**
7. **Real + BitFit**

The real-only regime provides the common reference condition. Every augmented
regime uses the same real training data plus 10,000 synthetic cases.

For the full downstream methodology, see
[`../docs/downstream_evaluation.md`](../docs/downstream_evaluation.md).

## Frozen real-data split

The real downstream-training set contains:

```text
332 BraTS subjects
41,460 training slices
```

The held-out BraTS validation set contains:

```text
37 BraTS subjects
5,735 validation slices
```

The same real training and validation manifests are used across downstream
regimes.

The 10,000 donor slices reserved for construction of the synthetic library do
not appear in the 41,460-slice real downstream-training manifest. This prevents
an exact synthetic donor slice from also being presented to the segmentation
model as a real training example.

The separation is defined at the slice level with respect to the synthetic
donor pool. Other non-donor slices from the same BraTS subject may remain in
the real downstream-training set.

## Frozen 10,000-case synthetic design

Synthetic augmentation is based on a shared frozen design containing:

```text
10,000 synthetic cases
40 batches
250 cases per batch
125 external BraTS validation subjects
80 cases per external subject
```

The design fixes the base/donor case assignments and enforces anatomical
compatibility, unique donor slices, donor-subject limits, and deterministic
case identifiers.

The same case design is used for BR-LoRA and the deterministic PEFT
comparators, reducing differences attributable to independently chosen
synthetic cases.

For complete design and production details, see
[`../docs/synthetic_library.md`](../docs/synthetic_library.md).

## Synthetic generation

BR-LoRA provides two downstream augmentation strategies.

**Posterior mean** uses one fixed synthetic image per frozen design case
generated from the posterior-mean BR-LoRA parameters.

**Posterior sampling** retains 100 posterior realizations per synthetic case.
For downstream training, the realization order is deterministically defined
for each case. With seed 42 and 20 training epochs, each case contributes 20
distinct posterior realizations across training.

Regional LoRA, DoRA, LoKr, and BitFit each provide one deterministic prediction
per frozen case. Their synthesis workflow reuses the corresponding accepted
BR-LoRA diffusion state, including the fixed reference diffusion noise.
Consequently, the deterministic methods are evaluated using the same frozen
case assignments and corresponding diffusion realization rather than receiving
independently sampled diffusion trajectories.

## Synthetic composition

Two synthetic-composition conditions are retained in the curated external
results.

### Feathered

The feathered condition uses the configured deterministic inner-only
distance-feathering rule when incorporating the generated tumor region into
the synthetic training image.

The current composition uses a four-pixel Euclidean inner feather. Pixels
outside the lesion mask remain equal to the base image, while the contribution
from the generated prediction increases toward the lesion interior.

### Non-feathered

The non-feathered condition uses the corresponding synthetic tumor region
without the downstream feathering operation.

Feathering is therefore a property of synthetic augmentation construction
during downstream training. It is not applied to UCSF-PDGM images during
external inference.

The two conditions are preserved side by side to document the observed
dependence of downstream performance on this composition choice. No direct
feathered-versus-non-feathered hypothesis test was performed.

## Downstream segmentation training

The real-only model is trained on:

```text
41,460 real samples per epoch
```

Each synthetic-augmentation regime is trained on:

```text
41,460 real samples
+ 10,000 synthetic samples
= 51,460 samples per epoch
```

All regimes use the same downstream segmentation framework: a single-channel
FLAIR 2D U-Net trained for 20 epochs using BCE-with-logits plus Dice loss,
Adamax optimization with learning rate 0.001, and a segmentation threshold of
0.5.

The real-data manifests, held-out BraTS validation cohort, segmentation
architecture, objective, optimizer, training duration, augmentation pipeline,
threshold, and evaluation definitions are held fixed. The synthetic
augmentation source is the experimental factor across the augmented regimes.

The best downstream checkpoint is selected using tumor-positive Dice on the
same frozen 37-subject BraTS validation cohort.

## Independent UCSF-PDGM external evaluation

All trained downstream models are evaluated on the same frozen independent
UCSF-PDGM cohort.

The frozen external cohort contains:

```text
202 baseline UCSF-PDGM subjects
```

It was derived after excluding UCSF-PDGM records overlapping the BraTS 2021
segmentation cohort and removing the follow-up examination from the remaining
independent cohort. No UCSF-PDGM subject is used for downstream model training
or model selection.

Evaluation uses the FLAIR modality and defines whole tumor as:

```text
segmentation > 0
```

Predictions from all axial slices are reassembled into complete 3D subject
volumes. The primary result reported here is therefore true subject-level
volumetric Dice rather than an average of slice-level Dice scores.

For UCSF-PDGM cohort derivation, preprocessing, validation, and evaluator
details, see
[`../docs/ucsf_pdgm_external_validation.md`](../docs/ucsf_pdgm_external_validation.md).

## Statistical analysis

For each training regime, the reported point estimate is the arithmetic mean
subject-level volumetric Dice across the same 202 UCSF-PDGM subjects.

Uncertainty is estimated using:

```text
10,000 nonparametric subject-level bootstrap resamples
bootstrap seed: 2026
95% percentile confidence intervals
```

The bootstrap standard error is the sample standard deviation of the 10,000
bootstrap estimates of the mean.

Differences from real-only training use paired subject-level resampling. The
same sampled subject indices are used across regimes within each bootstrap
replicate, preserving the matched external-cohort comparison.

The combined feathered/non-feathered table below is reporting-only. It
consolidates the two locked analyses and does not recompute Dice estimates,
bootstrap estimates, confidence intervals, or direct comparisons between the
two composition conditions.

## Curated result artifacts

The underlying curated analyses are retained under:

```text
downstream_segmentation/external_validation/ucsf_pdgm/peft_comparison/
├── feathered/
│   └── seed_42/
├── non_feathered/
│   └── seed_42/
└── combined/
    └── seed_42/
```

The `feathered/` and `non_feathered/` directories preserve their respective
locked volumetric-Dice analyses, including machine-readable statistical
provenance.

The `combined/` directory contains the reporting-only side-by-side
consolidation used in this README.

Raw, recomputable evaluation products remain under `outputs/`, while persistent
trained downstream model bundles are maintained separately under
`checkpoints/downstream_segmentation/`.
