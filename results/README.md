# Results

This directory contains curated results from the finalized analyses in this
repository. Intermediate evaluation outputs and run-specific artifacts are
kept separately under `outputs/`.

## UCSF-PDGM external downstream segmentation

The downstream segmentation experiment evaluates models on the frozen
202-subject UCSF-PDGM external cohort after exclusion of subjects overlapping
with BraTS.

All downstream models use the same segmentation architecture and evaluation
protocol. The real-only model is compared with models trained using the same
real downstream-training data augmented with synthetic images generated by
BR-LoRA or deterministic PEFT comparators.

Two synthetic-image composition conditions are retained:

- **Feathered:** synthetic tumor regions use the configured deterministic
  inner-only distance feathering step.
- **Non-feathered:** synthetic tumor regions are used without that downstream
  feathering step.

The table reports mean subject-level volumetric Dice with bootstrap standard
error, 95% percentile confidence interval, and the paired mean difference
relative to real-only training. Inference uses 10,000 paired subject-level
bootstrap resamples with seed 2026.

### Detailed result artifacts

The corresponding curated tables and statistical provenance are retained
under:

- `downstream_segmentation/external_validation/ucsf_pdgm/peft_comparison/feathered/seed_42/`
- `downstream_segmentation/external_validation/ucsf_pdgm/peft_comparison/non_feathered/seed_42/`
- `downstream_segmentation/external_validation/ucsf_pdgm/peft_comparison/combined/seed_42/`

The feathered and non-feathered directories contain the individual volumetric
Dice analysis tables and provenance JSON files. The combined directory contains
the reporting-only side-by-side consolidation of those locked analyses.
